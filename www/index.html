使用前请读一下

DSChat 是一个第三方 API 客户端，只做一件事：把你输入的内容发给你自己的 DeepSeek API Key 对应的官方接口，再把回答显示出来。

  • 与深度求索（DeepSeek）没有隶属、合作或授权关系，不是官方应用，也不代表官方立场。
  • 不托管你的 API Key。Key 只存在这台手机上，请求由 App 直接发往 api.deepseek.com。
  • 不中转流量、没有服务器。开发者看不到你的对话内容，也无法读取或撤销你的 API 用量。
  • 对话由 DeepSeek 模型生成，费用由你在 DeepSeek 平台的账户承担；使用时请一并遵守 DeepSeek 的服务条款。
  • 本项目以 MIT 协议免费开源，按「现状」提供，不附带任何担保。
