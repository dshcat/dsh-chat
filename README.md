# DSChat ULW

一个 Android 版 DeepSeek 客户端：WebView 壳 + 纯静态前端，无后端、无账号、无埋点。

- 版本 **5.0.0**，安装包约 **130 KB**
- 包名 `com.dsh.deepchat`　minSdk 26（Android 8+）　targetSdk 34
- MIT 协议，可自由修改、分发

非官方项目，与深度求索（DeepSeek）公司无任何隶属、合作或授权关系。

## 适合谁

适合把它当作日常聊天工具来用的人：所有设置集中在一处，操作路径短，可调的选项多一些，长时间用下来更顺手。功能都围绕「对话」本身，没有开发者工具，也不需要写任何配置。

## 声明

- 本项目只是一个 **API 调用客户端**：把你在界面上输入的内容，用你自己的 API Key 直接发到 `api.deepseek.com`。
- **不托管密钥**：Key 只保存在设备本地，不上传、不经过任何服务器。
- **不中转流量**：没有后端，开发者看不到对话内容，也无法读取或撤销你的 API 用量。
- **不隶属官方**：不是 DeepSeek 官方应用，不代表其立场；对话内容由 DeepSeek 模型生成。
- 费用由 Key 持有者在 DeepSeek 平台自行承担，使用时请一并遵守 DeepSeek 的服务条款。
- 以 MIT 协议免费开源，按「现状」提供，不附带担保。

首次启动会弹一次上述说明，同意后不再打扰。

## 功能

**对话**

- 流式输出、停止生成、复制、重新生成
- 真正的对话分支：编辑较早的提问后，后面那些轮次会收进旧版本的分支里；切回旧版本时，它后面的对话一起回来
- 两套独立版本：提问下方 `‹ 2 / 3 ›` 切换问法，回答下方 `‹ 1 / 2 ›` 切换重新生成的回答，数量无上限
- 每条消息带日期与时间，跨天自动插入日期分隔
- 推理等级四档：不思考 / 低 / 高 / 最高（对应接口的 `thinking` 与 `output_config.effort`）
- 联网搜索 + 读链接，带工具进度、来源列表和 `[1]` 引用角标
- 左侧问题跳转条：超过 3 条提问时出现，轻点弹出列表，按住上下滑直接跳转
- 抽屉搜索：搜标题、提问、回答，命中片段高亮
- 列表按日期分组：今天 / 昨天 / 近 7 天 / 本月 / 更早
- 置顶、收藏（收藏后需先取消收藏才能删除）
- 批量管理：长按对话或点抽屉右上角「批量」，可批量收藏、归档、删除
- 归档箱：归档的对话不占普通列表，点开可以继续聊

**附件**

- 图片、文本文件、PDF / Word / PowerPoint，一条消息最多 20 个，可多选
- 图片横向排列、可滑动，点开全屏后支持双指缩放、拖动、双击放大
- 待发送的附件也能点开预览
- 图片压缩开关：开启时缩到 1024px 再发，关闭则原图发送
- 被接口拒绝时会先压缩重试，不会静默丢图

**外观**

- 浅色 / 深色 / 跟随系统
- 自定义背景：8 个预设色 + 任意取色 + 相册图，可拖动缩放决定裁剪范围
- 背景透明度 20%–100%
- 用户与 AI 各一个圆形头像，可自定义并裁剪
- 应用图标可替换（App 内图标、启动页、AI 默认头像）
- 界面元素全部跟随主题配色

**用量与上下文**

- 每条回复下方列出：命中缓存 / 未命中 / 输出 / 思考 tokens + 人民币花费
- 输入框上方的圆环显示当前对话的上下文占用，点开看已用 / 剩余 / 上限
- 30 天用量账本：可按日期搜索，逐日列出 token 明细与花费，可一键清空
- 自动压缩上下文：超长时省略最早的对话并在 system 中注明；单条过长会截断并标注；可关闭
- 费用按官方价格估算（flash 输入 1 元/百万、缓存命中 0.02、输出 4；高峰期 ×2），不含搜索费，仅供参考

**其他**

- 对话级设置：名称、系统提示词、温度、头像、背景可单独覆盖全局
- 全局温度、Top P 可调
- 语言：简体中文 / 繁體中文 / English
- App 内提供更新公告与用户须知
- 一键导出 / 恢复备份（JSON，含全部对话与设置，不含 API Key）

## 安装

1. 下载 `DSChat-5.0.0.apk`
2. 点开安装，允许一次「未知来源」
3. 打开 → 左上角 ☰ → 设置 → 填 API Key（platform.deepseek.com 申请）

Key 只写在本机，不发往任何第三方；聊天请求直接发到 `api.deepseek.com`。

## 隐私

- 没有账号、没有统计、没有崩溃上报
- 对话、提示词、背景、头像都只在设备本地
- 唯一的对外请求是 DeepSeek API（以及你点开的网页链接，交给系统浏览器）
- 卸载应用会一并清除本地数据

## 数据与备份

- 对话正文（消息、版本、附件）存在 **IndexedDB**，容量随手机剩余空间，纯文字可存上万个对话
- 设置（Key、提示词、主题、头像、背景）存在 localStorage，并在 IndexedDB 留一份备份
- 设置 → 数据 → 「导出备份」会把全部对话与设置写成 JSON 存到手机「下载」目录（不含 API Key）；「恢复备份」可从文件读回并覆盖

没有账号系统，数据不跨设备同步。要做多设备同步需要服务器、数据库、鉴权与合规，不是打包能解决的；在那之前，导出文件 + 存网盘是最便宜可靠的方案。

## 自己编译

```bash
bash build.sh      # 产出 DSChat-5.0.0.apk
```

依赖：JDK 17、Android build-tools 34 的 `lib/d8.jar` 与 `lib/apksigner.jar`、`platforms/android-33/android.jar`、系统的 `aapt`。

> 为什么不用 aapt2 / Gradle：本项目在 arm64 手机上开发，Google 官方的 `aapt2`、`zipalign` 只有 x86_64 二进制。因此资源用 arm64 的 `aapt` 打，dex 用纯 Java 的 `d8.jar`，对齐用 `tools/zipalign.py` 重写 zip，签名用 `apksigner.jar`。全程不需要 Gradle。

签名：`build.sh` 会在本地生成 `release.keystore`（密码 `deepchat`）。**这个文件不要丢**，否则后续版本无法覆盖安装。它已被 `.gitignore` 排除，不会进仓库。

## 目录

```
www/            前端：index.html / app.css / app.js（无构建步骤）
android/        壳工程：AndroidManifest.xml、res/、java/
tools/          zipalign.py（纯 Python 对齐）、server.js（本地联调假接口）
test/           jsdom 回归测试
build.sh        一键打包
```

## 其他平台

界面是纯网页，理论上可以部署到静态托管后用浏览器打开：

- iPhone：Safari 打开后添加到主屏幕
- Windows / macOS：Chrome / Edge 打开后安装为应用
- 鸿蒙 4.x 及以下：直接装这个 APK
- 鸿蒙 NEXT：浏览器打开网页版

目前只发布 Android 安装包。
