# DSChat ULW

**一个用来聊天的 Android 客户端。** 不是开发工具，不是模型框架，也没有一行代码需要你写。

它只做一件事：把你在界面上输入的内容，用你自己的 DeepSeek API Key 发到官方接口，再把回答显示出来。
除此之外的一切 —— 账号、登录、广告、推荐、埋点、云端同步、会员等级 —— 都没有。

- 版本 **5.0.0**　安装包约 **130 KB**　包名 `com.dsh.deepchat`
- minSdk 26（Android 8+）　targetSdk 34
- **MIT 协议**，免费、可自由修改与分发

> 非官方项目，与深度求索（DeepSeek）公司没有任何隶属、合作或授权关系。

---

## 它想解决什么问题

官方 App 很好用，但用久了总有些地方不顺手：想换个背景、想把这句话改一下重新问、想翻回三个月前那个对话、想知道今天到底烧了多少钱、想把系统提示词固定成自己的习惯 —— 这些它都不给你。

DSChat ULW 就是把这些「不给」补上：

- **界面是你的**：主题、背景、透明度、头像、甚至 App 内图标，都能换
- **对话是你的**：本地保存、置顶、收藏、归档、批量管理、全局搜索
- **问法是你的**：系统提示词想写什么写什么，一句话可以反复改、反复重生成，历史一条不丢
- **钱是你的**：每一条回复花多少、命中多少缓存，全部列给你看

它没有登录，因为不需要；没有服务器，因为不中转；没有统计，因为不关心。

## 声明

- **只是一个客户端**：从你的手机直连 `api.deepseek.com`，中间没有任何中转。
- **不托管密钥**：API Key 只保存在设备本地，不上传、不经过开发者。
- **不中转流量**：没有后端服务器，开发者看不到你的对话，也无法读取或撤销你的用量。
- **不隶属官方**：不是 DeepSeek 官方应用，不代表其立场；对话由 DeepSeek 模型生成。
- **费用自理**：由 Key 持有者在 DeepSeek 平台承担，使用时请一并遵守其服务条款。
- **按现状提供**：MIT 协议免费开源，不附带任何担保。

首次启动会弹一次上述说明，同意后不再打扰。

## 功能

### 对话

- 流式输出、随时停止、复制、错误重试
- **真正的对话分支**：编辑较早的提问后，后面那些轮次会收进旧版本的分支，界面只留新分支；切回旧版本时，它后面的对话也一起回来
- **两套独立版本器**：提问下方 `‹ 2 / 3 ›` 切换问法，回答下方 `‹ 1 / 2 ›` 切换重新生成的回答，互不干扰，数量无上限
- 重新生成只允许在最后一条回答上做（避免把上下文弄乱）；要改前面的用「编辑」
- 每条消息带日期和时间，跨天自动插入日期分隔
- 左侧问题跳转条：对话超过 3 条提问时出现，轻点弹出列表（显示提问前五个字），按住上下滑可直接跳转
- 抽屉搜索：搜标题、提问、回答，命中片段高亮
- 列表按日期分组：今天 / 昨天 / 近 7 天 / 本月 / 更早
- 置顶、收藏（收藏后需先取消收藏才能删除）
- 批量管理：长按对话或点抽屉右上角「批量」，可批量收藏、归档、删除
- 归档箱：归档的对话不占普通列表，点开可以继续聊，并带独立的归档提示条

### 思考与联网

- 推理等级四档：**不思考 / 低 / 高 / 最高**，对应接口的 `thinking` 与 `output_config.effort`
- 深度思考内容可折叠查看，生成过程中也能拖动翻看
- 联网搜索 + 读链接，带搜索进度、来源列表和 `[1]` 引用角标
- 联网开关随时切换，按次计费的部分单独提示

### 附件

- 图片、文本文件（txt / md / csv / json / 代码）、PDF / Word / PowerPoint
- 一条消息最多 **20 个**附件，可一次多选
- 图片可横向滑动查看，点开全屏，支持**双指缩放 / 拖动 / 双击放大**，同组内左右滑切换
- 待发送的附件也能点开预览
- **图片压缩开关**：开启时缩到 1024px 再发；关闭则原图直发（更清晰，也更吃流量）
- 图片被接口拒绝时会先压缩重试，不会静默丢图

### 外观

- 浅色 / 深色 / 跟随系统
- 自定义背景：8 个预设色 + 任意取色 + 相册图，选图后可拖动缩放决定裁剪哪一块
- 背景透明度 20%–100%，从几乎实心到能看清图
- 用户与 AI 各一个圆形头像，可自定义并裁剪
- **应用图标**可替换（App 内图标、启动页、AI 默认头像）—— 桌面图标由系统决定，改不了
- 界面元素全部跟随主题配色

### 用量与费用

- 每条回复下方列出：**命中缓存 / 未命中 / 输出 / 思考 tokens + 人民币花费**
- 输入框上方的圆环显示当前对话的上下文占用，点开看已用 / 剩余 / 上限
- 30 天用量账本：可按日期搜索，逐日列出 token 明细与花费，可一键清空
- 费用按官方价格估算（`deepseek-flash` 输入 1 元/百万、缓存命中 0.02、输出 4；**高峰期 ×2**），不含搜索费，仅供参考

### 上下文

- 自动压缩：内容超长时先省略最早的对话，并在 system 里说明「更早的对话已省略」
- 单条消息过长时会截断，并标注截断了多少字
- 服务端返回上限时，会记住这个值并按它重裁重发
- 可以在设置里关掉自动压缩（关掉后原样发送，超限会直接报错）

### 其他

- 对话级设置：名称、系统提示词、温度、头像、背景都能单独覆盖全局
- 全局温度、**Top P** 可调（Top P 控制候选词的累计概率，越接近 1 越自由）
- 语言：简体中文 / 繁體中文 / English
- 更新公告与用户须知，都做在 App 里
- 一键导出 / 恢复备份（JSON，含全部对话与设置，不含 API Key）

## 安装

1. 下载 `DSChat-5.0.0.apk`
2. 点开安装，允许一次「未知来源」
3. 打开 → 左上角 ☰ → 设置 → 填入 API Key（在 [platform.deepseek.com](https://platform.deepseek.com) 申请并充值）

Key 只写在本机，不发往任何第三方；聊天请求由 App 直接发到 `api.deepseek.com`。

## 数据存在哪

- **对话正文**（消息、版本、附件）：**IndexedDB**，容量随手机剩余空间，通常几百 MB 起，纯文字能存上万个对话
- **设置**（Key、提示词、主题、头像、背景）：localStorage + IndexedDB 双份备份
- 卸载应用会一并清除全部本地数据

设置 → 数据 → 「导出备份」会把全部对话与设置写成 JSON 存到手机「下载」目录；「恢复备份」可从文件读回并覆盖。

**没有账号系统**，数据不跨设备同步。真要做云同步，需要服务器、数据库、鉴权与合规，不是打包能解决的；在那之前，导出文件 + 存网盘是最便宜可靠的方案。

## 自己编译

```bash
bash build.sh      # 产出 DSChat-5.0.0.apk
```

依赖：JDK 17、Android build-tools 34 的 `lib/d8.jar` 与 `lib/apksigner.jar`、`platforms/android-33/android.jar`、系统的 `aapt`。

> 为什么不用 aapt2 / Gradle：本项目在 arm64 手机上开发，Google 官方的 `aapt2`、`zipalign` 只有 x86_64 二进制。因此资源用 arm64 的 `aapt` 打，dex 用纯 Java 的 `d8.jar`，对齐用 `tools/zipalign.py` 重写 zip，签名用 `apksigner.jar`。全程不需要 Gradle。

签名：`build.sh` 会在本地生成 `release.keystore`（密码 `deepchat`）。**这个文件不要丢**，否则后续版本无法覆盖安装。它已被 `.gitignore` 排除，不会进仓库。
